# Contact

問い合わせ窓口ページ (`/contact`) の位置づけ、相談内容ごとの窓口の振り分け、宛先の提示方法を扱う。

## 位置づけ

`/contact` は、BSI ポータル自体 (使い方 / 掲載内容 / 表示の不具合) の一次窓口を 1 ページにまとめ、それ以外の相談については既存の運用窓口を案内する。

ページは送信 form を持たない。利用者は自分のメールクライアントで問い合わせを作成して送信する。BFF は問い合わせの内容を受け取らず、このページに対応する endpoint は存在しない。

## 窓口の振り分け

| 相談内容 | 送り先 |
|---|---|
| BSI ポータルの使い方 / 掲載内容 / 表示の不具合 | BSI ヘルプデスク |
| 各 DB へのデータ登録 / 公開 / 登録内容の更新 | DDBJ お問い合わせ |
| DBCLS が提供するデータベース / ツール | DBCLS お問い合わせ |
| 遺伝研スーパーコンピュータの利用 | 遺伝研スパコン質問窓口 |

宛先アドレスと外部窓口の URL は `app/features/contact/helpdesk.ts` を SSOT とする。外部窓口の URL は ja / en で別に定義する。

ページでは、利用者が問い合わせる前に自己解決できるリンク (ナレッジベース / DDBJ FAQ / サービス一覧) を、メールの窓口より上に置く。

## 窓口の提示

ページは `mailto:` link を置かない。`mailto:` link を押したときにメールクライアントが開くかどうかは環境ごとに異なり、Web メールの利用者には何も起きないためである。宛先の提示方法は、アドレスの平文表示とコピーボタンの 2 つに固定する。

- 宛先アドレスは、利用者が選択できる平文テキストとして表示する
- アドレスの横にコピーボタンを置く。利用者が押すと、一定時間だけ成功のフィードバックを表示し、`role="status"` でも通知する
- clipboard API が使えない環境ではフィードバックを出さず、利用者が表示中のアドレスを自分で選択してコピーする
- 問い合わせに書いてほしい項目は、ページ本文に一覧で示す

## レイアウト

枠線付きのカードはリンク (自己解決のリンクと他の問い合わせ先) にだけ使い、メールの窓口には使わない。カードの寸法と間隔は top page の service grid に合わせる。セクションをまたいで列数を揃えることで、カード 1 枚の幅をページ内で一定に保つ。

## /contact へのリンク

`/contact` へのリンクは次の 3 箇所にある。ページを追加または削除したときは、この 3 箇所をすべて合わせて更新する。

- header の main nav
- `/docs` の目次。`page-contents/sitemap.json` の `support` セクションに書く
- `/sitemap.xml`。`server/api/sitemap.ts` の `STATIC_PATHS` に書く
