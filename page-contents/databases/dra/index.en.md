## About DRA

DDBJ Sequence Read Archive (DRA) is a public archive for sequence read data from next-generation sequencers. It accepts FASTQ and BAM read files along with experiment metadata (Experiment / Run). Submitted data is continuously exchanged with INSDC partners (NCBI SRA / EBI ENA).

> [!NOTE]
> Choose "sequence reads" in the [submission navigator](/submit) to see the BioProject → BioSample → DRA registration path assembled automatically.
