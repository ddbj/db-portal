## DDBJ (MSS) とは

DDBJ の MSS (Mass Submission System) は、大量の塩基配列やアノテーション付き配列を一括登録するためのシステムです。
WGS (Whole Genome Shotgun)、完成ゲノム (GNM)、MAG (Metagenome-Assembled Genome)、TSA (Transcriptome Shotgun Assembly)、TLS (Targeted Locus Study)、TPA (Third Party Annotation) など、Division と data type に応じた分類で受け付けます。

> [!NOTE]
> [登録ナビ](/submit) で塩基配列を選ぶと、BioProject・BioSample・DDBJ の登録経路が組み立てられます。
