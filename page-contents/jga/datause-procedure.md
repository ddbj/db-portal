## データ利用申請の具体的な手順

**データ利用申請グループの作成：**

  - [申請システム](https://humandbs.ddbj.nig.ac.jp/nbdc/application)へログイン後の画面左側にあるメニューの [グループ作成] を選択
  - グループ名、グループの説明、グループ種別「データ利用申請グループ」を入力し、[保存]ボタンを押下
  - 作成したデータ提供申請グループにメンバを追加
    - [メンバタブ] の [メンバを招待する] ボタンをクリック
    - 研究代表者、申請者、データダウンロード担当者の**所属機関が発行したメールアドレス**もしくは**DDBJアカウント**を入力
    - [招待]ボタンを押下すると、招待されたメンバへメールが送付される。
    - メールの記載内容に沿ってメンバにより招待が承諾されると、グループにメンバとして登録される。
  - データ利用申請の際の研究代表者にPI権限を付与する
    - Owner権限が付与されたメンバが変更可能
    - データ利用申請の際の研究代表者がグループを作成した場合は、既にPI/Ownerになっているため、変更不要
    - 該当するメンバの PI 横のラジオボタンを選択し、[Owner/PI 変更]を押下

      
**DDBJ アカウント情報の変更：**

  - 日本語表記の氏名、所属機関、所属部署、職名、電話番号、英語表記の所属部署の住所、所属機関、所属部署、職名情報が必要
    - 申請者情報は、DDBJ アカウントの情報が自動的にシステムへ反映されるため、DDBJ アカウントの登録情報への追記が必須
  -  [申請システム](https://humandbs.ddbj.nig.ac.jp/nbdc/application)へログイン後、画面右上にある「アプリケーション一覧」の[DDBJ Account]をクリック
  -  情報を更新後、[Update Profile]をクリック


**データ利用申請：**

  - [申請システム](https://humandbs.ddbj.nig.ac.jp/nbdc/application)へログイン後、[データ利用申請を行う]をクリック
  - 「日本国内からの申請」/「日本国外からの申請」いずれかを選択のうえ、[新規申請を開始する]をクリック
  - 入力フォームへ必要事項を記載し、必要書類を添付する
    - データ利用申請グループを選択
    - 研究代表者を修正したい場合は、データ提供申請グループの登録情報を修正する
    - 所属機関の長とは、倫理審査委員会によって承認された研究計画の実施を許可する者を指すため、審査結果通知書等に記載された「研究機関の長」に該当する役職の現職者情報を入力する
    - 研究題目には、倫理審査委員会による承認と所属機関の長による実施許可を受けた研究計画書に記載された研究題目名を記載する
    - 書類を添付する際には、1 つ以上の file type を指定する
  - 「概要」ページにて、入力内容な間違いが無いか確認のうえ、[申請]ボタンを押下
